## 少一点切换，多一点专注

![AERO 迷你状态栏宣传：六个任务灯，安静地留在视野里](docs/images/aero-promo-mini.png)

**完整控制栏**把任务状态、推理强度、新建、继续和中断等操作集中在桌面上。控件可以隐藏，也可以拖拽排序，只留下你真正需要的部分。

**迷你状态栏**保留六个任务灯和一个返回按钮。它可以自由拖动，靠近屏幕边缘时吸附；完整栏也能一键收缩，在你处理其他事情时安静地留在视野边缘。

  <img src="docs/images/aero-mini.png" width="360" alt="AERO 迷你状态栏：六个任务状态灯与一个返回按钮" />
</p>

悬停查看工作区名和线程名，点击状态灯打开对应的 Codex 任务。任务从运行变为完成时，可播放轻柔提示音。

## 一眼读懂任务状态

状态灯不靠常驻的鲜艳颜色争夺注意力，而是在任务状态变化时传递信息。大小控制栏使用一致的状态语义；颜色可以在设置中按你的偏好调整。

| 状态 | 默认颜色 | 含义 |
| --- | --- | --- |
| 空闲 · Idle | 白色 | 当前没有正在进行的工作 |
| 运行 · Thinking | 蓝色 | Codex 正在处理任务 |
| 完成 · Complete | 绿色 | 任务完成，等待你查看 |
| 需要输入 · Needs input | 黄色 | 需要回应或处理批准请求 |
| 错误 · Error | 粉色 | 任务出现错误，需要关注 |

## 把控制栏变成你的样子

圆角、柔和阴影、克制的半透明材质，以及平滑的非线性过渡，让 AERO 像桌面上的一件小工具，而不是另一扇需要管理的窗口。

- 大小控制栏分别选择冷白或深色外观，设置页跟随完整栏主题。
- 控件拖拽排序，自定义显示项和界面密度。
- 状态灯支持预设色板与颜色代码输入。
- 标志支持 Air、Mint、Sunset、Mono 配色，也可选择透明底色或隐藏标志。
- 交互声音可以关闭。窗口可隐藏到系统托盘，托盘菜单提供显示、语音入口和退出操作。

![AERO 外观设置：品牌配色、控制栏材质与界面密度](docs/images/aero-settings.png)

## 常用操作，随手可达

AERO 可以打开和切换任务、新建任务、继续或中断工作、调整推理强度，并提供任务分支、归档、复制 Markdown、打开工作目录与终端等可选控件。

推理档位跟随 Codex 模型公布的能力显示，包括支持时的 `Max` 和 `Ultra`。批准与拒绝只针对 AERO 当前收到的具体请求，不提供跨线程的“全局批准”。

## “Hey Codex”，本地唤醒

![AERO 本地唤醒配置：绑定热键、配置环境、选择麦克风、开启监听](docs/images/aero-promo-voice.png)

可选的离线监听使用 Vosk 和本机麦克风。识别到唤醒词后，监听器会先释放麦克风，再发送 `Ctrl+Shift+V`，将语音入口交给 Codex Desktop。

![AERO 语音设置：监听开关、唤醒词、麦克风与一键配置](docs/images/aero-voice.png)

### 配置监听

1. **绑定热键**：在 Codex Desktop 的快捷键设置中，将 Voice 显式绑定为 `Ctrl+Shift+V`。AERO 只检查，不替你更改。
2. **配置环境**：打开 AERO 的「设置 → 语音」，点击「一键配置」，等待运行环境与英文模型就绪。已有环境也可手动选择 Python 可执行文件与解压后的 Vosk 模型文件夹。
3. **选择麦克风**：选择你实际使用的输入设备，唤醒词保持 `Hey Codex`，点击「检查配置」。不要沿用他人机器的设备编号。
4. **开启并试说**：打开「监听」开关，确认状态为「监听中」，再说出 `Hey Codex`。配置检查通过不等于真人唤醒已经成功，需实际观察 Codex Voice 是否打开。

关闭悬浮窗只是隐藏到托盘，已开启的监听仍在后台运行；关闭监听开关或从托盘退出 AERO 才会停止监听。成功触发后，监听器释放麦克风并退出；Voice 结束后，在语音设置点击「重新监听」。

**手动语音入口**：不想持续监听时，关闭监听开关，使用控制栏语音按钮或托盘语音菜单尝试打开 Voice 即可。

无响应时，依次核对热键绑定、麦克风选择、环境与模型路径，并从语音设置打开日志。更完整的说明见 [使用指南](docs/USAGE.md#可选本地语音唤醒)。

- 本地唤醒不调用 OpenAI API、不上传音频，不消耗 Codex token 或云端语音额度；启动后的 **Codex Voice 本身仍遵循 Codex 的使用规则和额度**。
- 设置中可选择麦克风、调整唤醒词、查看运行状态与日志，并一键配置隔离的 Python 环境和英文模型。首次配置需要联网下载，之后识别在本地运行。
- 默认不保存原始音频或日常转写。关闭监听或从托盘退出 AERO 会结束监听进程。
- 请先在 Codex 快捷键设置中显式绑定 Voice 到 `Ctrl+Shift+V`。AERO 会检查绑定，但不会替你修改 Codex 的设置。
- 触发后监听器保持退出。Voice 结束后，需要手动重新监听；当前不自动判断语音会话结束。

## 开始使用

当前提供源码运行方式，尚无安装包。需要 Windows、Node.js 24 LTS、npm，以及已安装并登录的 Codex Desktop。

请先阅读下方授权说明，再按适用的授权范围获取源码。

```powershell
git clone https://github.com/AeolusV/AERO.git
Set-Location AERO
npm.cmd ci
npm.cmd run build
npm.cmd start
```

开发模式：

```powershell
npm.cmd run dev
```

启动后，AERO 自动发现本机 Codex 后端。按需进入设置，选择控件、外观和语音选项。语音唤醒不是使用任务状态栏的前提。

更多操作和常见问题见 [使用指南](docs/USAGE.md)。修改代码前，请阅读 [开发指南](docs/DEVELOPMENT.md)；运行 `npm.cmd run verify` 可统一执行离线回归测试、类型检查和构建，不会启动麦克风监听或真实 Codex 会话。

## 兼容性与边界

AERO 是独立项目，不修改 Codex 安装包，不依赖隐藏的 Codex Micro 设置页，也不代表 OpenAI 官方产品。

- 已验证的 Desktop 版本为 `26.928.3736.0`。使用实验性 `app-server` 协议，Codex 更新可能带来接口变化。
- 任务状态由后端元数据与本地结构化事件共同判断，不是 Desktop 内部状态的直接镜像，可能有刷新延迟。
- 推理档位列表目前以默认模型为准。任务被 Desktop 独占时，档位修改可能回退为后续提交使用的默认配置，不等于同步修改当前输入框。
- 远程配对选项属于 Codex 的实验接口，不是智能家居连接。当前不提供智能家居控制。
- 语音热键发送成功不等于 Voice 会话已启动，仍需 Codex 可接收该热键并具备语音功能。

遇到问题，请在 [Issues](https://github.com/AeolusV/AERO/issues) 中描述 Windows / Codex 版本、复现步骤和预期行为。请勿上传凭证、私密对话或含敏感信息的日志。
