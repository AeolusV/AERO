# AERO · 0.1.0 Beta 2

**简体中文** · [English](BETA.en.md)

让任务留在视野里，让专注回到你手上。

AERO 为 Windows 上的 Codex Desktop 带来一条轻盈的悬浮控制栏。展开时把常用操作放在手边；收起时，让六个任务灯安静地陪伴你。

## Beta 2：更轻松地设置，更自然地唤醒

常用设置留在眼前，标志配色、灯色和语音细节按需展开。明暗外观保持一致，柔和的展开与收起让每一次调整更从容。

在语音页点击「准备语音」，选好麦克风，再说声 “Hey Codex” 试试。看到「听到了」，就可以开启监听。试听不会打开 Codex Voice，也可以随时暂停。首次下载后，唤醒识别在本地离线运行。

## 这个版本带来了什么

- 大小两种控制栏，随手拖动、靠边吸附，随时切换。
- 统一的任务状态灯、工作区与线程名称提示，以及可选的完成提示音。
- 深浅外观、自选灯色、可拖拽排列的控件，让它更贴合你的桌面。
- Codex 常用操作与 Windows 托盘入口。
- 可选的本地 “Hey Codex” 唤醒；监听不上传音频，触发后释放麦克风，再通过快捷键打开 Codex Voice。

## 开始体验

按[下载指南](DOWNLOADS.md)获取 Windows x64 便携包，完整解压后运行 `AERO.exe`，无需安装。语音唤醒需要另行配置本地环境、模型与麦克风；具体步骤见[使用指南](USAGE.md)。

## 使用前的小提醒

这是未签名的早期 Beta，Windows 可能显示安全提示，请保留系统保护。自动检查涵盖回归测试、类型检查、构建与隔离的打包启动，不代表所有真实桌面功能都已通过验收。

本轮不进行真人语音唤醒和完整桌面交互验收。Codex 版本变化也可能影响连接与操作。唤醒后自动重新监听尚未实现；需要时在设置里重新启动监听。离线唤醒本身不调用 OpenAI API，打开后的 Codex Voice 仍遵循 Codex 的使用规则。

发现问题，欢迎通过 [Issues](https://github.com/AeolusV/AERO/issues)告诉我们：AERO 与 Codex 版本、操作步骤、预期结果和实际表现即可。请勿附上密钥、私人对话或原始音频。
